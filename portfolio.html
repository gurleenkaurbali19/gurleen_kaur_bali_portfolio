Projects

CyberPulse

Demo preview

A full-stack SOC analytics platform that brings data from 6 security tools (CrowdStrike Falcon, Cyble, SIEM, Trend Vision, Netskope and Com Olho) into one place. A 3-layer MySQL database ends in a central kpi_master table, and an automated pipeline with SHA-256 duplicate detection computes KPIs with date-range filtering. The interactive Plotly dashboard (donuts, gauges, funnels, treemaps, area trends) is deployed on Streamlit Community Cloud with Aiven-hosted MySQL.

Python, MySQL, Streamlit, Plotly

GitHubLive project

IPCheck: Suspicious IP Tracker

Demo preview

A FastAPI backend with a trained Random Forest model predicts IP risk levels. A React frontend lets you upload CSVs, see the AI results and explore flagged IPs on an interactive world map. The backend runs on Render and the frontend on Vercel, with secure CORS handling and environment variables.

FastAPI, Random Forest, React, Render, Vercel
